## First-Stage Policy
- Do not require historical `mypy`, `pydocstyle`, or `radon` output to be clean before normal feature work.
- Use those tools to classify debt and improve touched files incrementally.
- Make `black --check`, `ruff check`, `npm run build`, `npm run lint`, and `npm run format:check` candidates for hard gates only after the first baseline pass shows they are stable.
